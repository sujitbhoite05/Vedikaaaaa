# Siddhi’s proposal website

Open `index.html` in a browser to preview it. It is a static site, so the complete folder can be deployed directly to GitHub Pages, Netlify, or Vercel.

## Personalize it

- Change the love-letter words and the signature in `index.html`.
- The site intentionally has no photo gallery, keeping the focus entirely on the proposal.
- The entrance screen starts the included `assets/perfect.mp3` when the visitor taps to open the letter. This one tap is necessary because browsers block unmuted music from starting silently on page load.

## Publish

- **Netlify:** drag this folder onto [Netlify Drop](https://app.netlify.com/drop).
- **GitHub Pages:** upload this folder to a repository, then enable Pages from the repository settings.
- **Vercel:** import the folder/repository and deploy with the default settings.
